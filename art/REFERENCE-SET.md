# Krita reference cast

This set contains all sixteen Bugglebrook bugs and a shared expression kit. Codex authored the reference drawings in Krita 6.0.4 at the owner's request on 2–3 October 2026. They are not artwork by the owner's daughter. Her drawings can be installed as a separate named set without replacing this reference.

Dot is the first production drawing from this experiment, described in `DOT-EXPERIMENT.md`. The other bugs use the same plum outline, cream eyes, flat shaded colors, and small painted highlights. Their shapes follow the existing species rigs. The later temporary Dot silhouette studies are not part of this set.

## What is included

Every bug has all required body parts and all 28 movable face pieces in its ORA. The shared `face_kit.ora` contains the same expression family for future drawings to use. The pack includes Rollo and Barty curled up, Glorp inside his shell, Munch's cocoon and butterfly parts, and the flying wings. Tintable Barty parts and sleepy eyelids use greys so the game can color them.

Sources live in `src/bugs/` and `src/faces/`. Keep their `.rig.json` companions unchanged. Each ORA retains the original guides, canvas, pivots and part names. Hidden expressions and forms still export. The straight source legs and antennae are posed by the game; the ORA's merged preview is not a finished standing pose.

Krita painted the paths, ellipses, fills, and strokes with its native Basic-5 Size brush and saved the layered OpenRaster files. Codex supplied the drawing instructions through an isolated local Python batch interface. This was brush scripting, not manual mouse drawing or text-to-image generation. The atlas PNGs and JSON files were generated by `pnpm art:build`.

## Review in the game

Open settings and use the Art arrows to select **Krita reference**. **Original bugs** restores the procedural drawings. Selection is stored with settings, outside the save slots. See `docs/06-art-guide.md` for adding another set with its own name and artist credit.

For a focused visual review on a virtual display:

```sh
BB_SHOTS_DIR=/tmp/bb-reference-shots pnpm shots -g 'Krita reference cast'
```

The tour captures every bug's pose and expression grid at 1x and 2x atlas resolution, larger idle/walk/held views, special forms, paint, and night tinting. Each comparison shows the procedural bug on the left and the Krita reference on the right. `tests/unit/referenceArt.test.ts` checks every shipped pose and expression without a shared face fallback.
